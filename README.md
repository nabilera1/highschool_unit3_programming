# 영단어 구조대(New HangMan Game)

**영단어 구조대 게임을 만들며 배우는 파이썬 프로그래밍** — 고등학교 「정보」 '프로그래밍' 단원(중학교 「정보」 프로그래밍 단원에도 활용 가능)을 위한 8차시 수업·연수 자료입니다.

원래 '행맨(Hangman)'은 단어를 못 맞히면 사람 그림이 완성되는 게임입니다. 이 자료에서는 이야기를 바꾸어, **영단어 암호를 맞혀 길을 잃은 친구를 구조하는 '영단어 구조대'** 게임을 단계별로 만들며 리스트·문자열·딕셔너리·함수·반복·조건·2차원 리스트를 배웁니다.

| 차시 | 단계 | 제목 | 핵심 개념 |
| --- | --- | --- | --- |
| 1 | 문제 발견 | 영단어 구조대 플레이하고 규칙 찾기 | 알고리즘, 입력, 자료(상태), 처리, 출력, 종료 조건 |
| 2 | 문제 구조화 | 규칙을 자료로 정리하기 – 단어장·암호·배터리 | 리스트, 인덱스, append, random.choice, 문자열(len, in), 문자열 곱하기, 추적표 |
| 3 | 컴퓨팅 설계 | 문자열·리스트·딕셔너리로 암호판 만들기 | for 문, 문자열 순회, 리스트 누적, join, 딕셔너리(키·값), 추가, list(딕셔너리) |
| 4 | 컴퓨팅 설계 | 함수로 나누기 – 함수 없는 코드와 함수 코드 비교 | 함수, def, 매개변수, return, 반환값, main(), 문제 분해, 재사용 |
| 5 | 구현 | while 문으로 영단어 구조대 게임 완성하기 | while 조건 반복, 종료 조건, return, 값 두 개 돌려주기, 무한 반복, for와 while |
| 6 | 구현 | 출동 기록표 – 2차원 리스트와 중첩 for 문 | 2차원 리스트, 행·칸, records[행][칸], append로 행 쌓기, 중첩 for 문, 조건으로 행 고르기 |
| 7 | 테스트 및 개선 | 이상한 입력 넣어 보고 고치기 – 테스트와 개선 | 테스트 케이스(정상·경계·예외), strip, lower, len, in, 입력 검사, 다시 묻는 반복 |
| 8 | 공유·확장 | 나만의 영단어 구조대 발표와 형성평가 | 프로젝트, 기능 설계, 발표, 동료 피드백, 형성평가, 글자 빈도 |

- 차시 순서와 코드는 교육청 수업 모형 문서(`teacher/lesson_model.hwpx`)와 같습니다.
- 기준 코드 `source/word_rescue.py`(함수 버전)와 `source/word_rescue_nofunc.py`(함수 없는 버전)를 4차시에 비교합니다.
