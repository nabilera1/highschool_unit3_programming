# 영단어 구조대(New HangMan Game)

**영단어 구조대 게임을 만들며 배우는 파이썬 프로그래밍** — 고등학교 「정보」 '프로그래밍' 단원(중학교 「정보」 프로그래밍 단원에도 활용 가능)을 위한 8차시 수업·연수 자료입니다.

원래 '행맨(Hangman)'은 단어를 못 맞히면 사람 그림이 완성되는 게임입니다. 이 자료에서는 이야기를 바꾸어, **영단어 암호를 맞혀 길을 잃은 친구를 구조하는 '영단어 구조대'** 게임을 단계별로 만들며 리스트·문자열·반복·조건·함수·딕셔너리·2차원 리스트를 배웁니다.

| 차시 | 단계 | 제목 | 핵심 개념 |
| --- | --- | --- | --- |
| 1 | 문제 발견 | 영단어 구조대 플레이하고 알고리즘 찾기 | 알고리즘, 입력, 처리, 출력 |
| 2 | 문제 구조화 | 리스트·random·문자열로 암호 고르기 | 리스트, 인덱스, random.choice, len |
| 3 | 컴퓨팅 설계 | for 반복문으로 밑줄 암호판 만들기 | for, range, 문자열 누적, end |
| 4 | 컴퓨팅 설계 · 구현 | while과 조건문으로 기본 버전 완성하기 | while, break, 종료 조건, 깃발 변수 |
| 5 | 테스트 및 개선 | 테스트 케이스로 오류 찾고 입력 검사하기 | 테스트 케이스, 정상, 경계, 예외 |
| 6 | 구현 | 함수로 나누어 코드 다듬기 | 함수, def, 매개변수, return |
| 7 | 구현 | 딕셔너리와 2차원 리스트로 게임 확장하기 | 딕셔너리, 키, 값, 2차원 리스트 |
| 8 | 공유·확장 | 나만의 영단어 구조대 프로젝트와 발표 | 프로젝트, 기능 설계, 글자 빈도, 확률 |
