> **3부 자료구조로 확장하고 프로젝트하기** · 7차시 · 수업 단계: **구현**  
> 핵심 개념: 딕셔너리, 키, 값, 2차원 리스트, 행, 열, 중첩 반복

## 학습 목표

1. 딕셔너리로 '영단어 → 뜻'처럼 짝지은 데이터를 저장하고 꺼낼 수 있다.
2. 2차원 리스트의 행과 열을 이해하고 중첩 for로 출력할 수 있다.
3. 딕셔너리와 2차원 리스트를 이용해 게임에 새 기능을 추가할 수 있다.

## 핵심 질문

> **암호마다 '뜻 힌트'를 붙이고, 출동 기록을 표로 남기려면 데이터를 어떻게 저장해야 할까?**

함수 버전 게임에 기능을 더해 봅시다. 사용자들이 이런 의견을 냈습니다.

- "단어 뜻을 힌트로 주면 영어 공부도 되겠어요."
- "주제(구조·안전, 마음·우정, 정보)와 난이도를 고르고 싶어요."
- "몇 번 출동해서 몇 명을 구했는지 기록표로 보고 싶어요."

이런 기능에는 **짝지은 데이터**(딕셔너리)와 **표 모양 데이터**(2차원 리스트)가 필요합니다.

## 딕셔너리: 키로 값을 찾는다

```python
뜻사전 = {'help': '도움', 'safe': '안전한', 'hope': '희망'}   # {키: 값}

print(뜻사전['help'])        # 도움     → 키로 값 꺼내기
뜻사전['care'] = '돌봄'       # 새 짝 추가
print(len(뜻사전))           # 4
print('safe' in 뜻사전)      # True     → 키가 있는지
for 단어 in 뜻사전:          # for 로 돌리면 키가 하나씩
    print(단어, 뜻사전[단어])
```

리스트는 **번호**(인덱스)로, 딕셔너리는 **이름**(키)으로 찾습니다.

## 딕셔너리 안의 딕셔너리, 점수 딕셔너리

```python
단어사전 = {
    '구조·안전': {'help': '도움', 'rescue': '구조', 'doctor': '의사', ...},
    '마음·우정': {'hope': '희망', 'friend': '친구', ...},
    '정보':     {'list': '리스트', 'loop': '반복', ...},
}
print(단어사전['정보']['loop'])      # 반복   → [주제][영단어]

점수 = {'구조': 0, '재출동': 0}
점수['구조'] += 1                     # 결과 이름으로 바로 세기
```

## 2차원 리스트: 행과 열

```python
난이도표 = [['쉬움',   3, 5,  True],     # 0행: [이름, 최소 글자, 최대 글자, 뜻 힌트]
            ['보통',   5, 6,  False],    # 1행
            ['어려움', 7, 20, False]]    # 2행
print(난이도표[1][0])     # 보통   → [행][열]
print(난이도표[2][1])     # 7

키보드판 = [list('qwertyuiop'), list('asdfghjkl'), list('zxcvbnm')]
for 행 in range(len(키보드판)):             # 바깥 반복: 줄
    for 열 in range(len(키보드판[행])):      # 안쪽 반복: 그 줄의 글자
        print(키보드판[행][열], end=' ')
    print()
```

| | 0열 (이름) | 1열 (최소) | 2열 (최대) | 3열 (힌트) |
| --- | --- | --- | --- | --- |
| 0행 | 쉬움 | 3 | 5 | True |
| 1행 | 보통 | 5 | 6 | False |
| 2행 | 어려움 | 7 | 20 | False |

## 기록표: 2차원 리스트에 한 줄씩 쌓기

```python
기록표 = []                                   # 빈 표
기록표.append([1, '구조·안전', '쉬움', 'help', '구조', 2])     # 한 판 끝날 때마다
기록표.append([2, '마음·우정', '보통', 'friend', '재출동', 6])

for 행 in 기록표:            # 표의 한 줄씩
    for 칸 in 행:            # 그 줄의 칸 하나씩
        print(str(칸).ljust(10), end='')
    print()
```

| 기능 | 사용한 자료구조 |
| --- | --- |
| 주제별 단어와 뜻 힌트 | 딕셔너리 안의 딕셔너리 `단어사전` |
| 결과별 횟수 | 딕셔너리 `점수` |
| 난이도 설정 | 2차원 리스트 `난이도표` |
| 키보드 모양 표시 | 2차원 리스트 `키보드판` + 중첩 for |
| 출동 기록 | 2차원 리스트 `기록표` + append |

```python
# =====================================================================
# 영단어 구조대 (확장 · 산출물 예시 버전)                  [7차시, 1차시 맛보기]

# 6차시 함수 버전에 '자료구조'를 더해 게임을 키웠어요.
#   딕셔너리   단어사전 = {주제: {영단어: 뜻}}   → 주제 고르기, 뜻 힌트
#   딕셔너리   점수 = {'구조': 0, '재출동': 0}   → 결과별 횟수 세기
#   2차원 리스트 난이도표[행][열]                → 난이도마다 [이름, 최소 글자, 최대 글자, 힌트 여부]

#   2차원 리스트 기록표                          → 출동할 때마다 한 줄씩 append, 마지막에 표로 출력
#
# 전체 흐름
#   main() → 번호선택(주제) → 번호선택(난이도) → 한판진행() → 기록표에 추가 → 다시 출동? → 기록표출력()
#   한판진행() 안에서: 비밀단어생성 → [반복] 게임화면생성 → 알파벳한글자리턴 → 판정
#
# 실행 방법: python new_rescue_3_project.py

import random

# 구조 신호 그림 리스트: 틀린 횟수가 곧 인덱스
신호그림 = ['[■■■■■■] 구조 신호 아주 강함',
            '[■■■■■□] 구조 신호 강함',
            '[■■■■□□] 구조 신호 양호',
            '[■■■□□□] 구조 신호 보통',
            '[■■□□□□] 구조 신호 약함 - 서둘러요!',
            '[■□□□□□] 구조 신호 아주 약함 - 마지막 기회!',
            '[□□□□□□] 구조 신호 끊김']
최대틀림 = len(신호그림) - 1                      # 6번 틀리면 신호가 끊김

# 딕셔너리 안의 딕셔너리: 주제 → {영어 단어: 한글 뜻}
단어사전 = {
    '구조·안전': {'help': '도움', 'safe': '안전한', 'rescue': '구조', 'doctor': '의사',
              'nurse': '간호사', 'hospital': '병원', 'emergency': '비상', 'firefighter': '소방관'},
    '마음·우정': {'hope': '희망', 'care': '돌봄', 'smile': '미소', 'thanks': '감사',
              'friend': '친구', 'kindness': '친절', 'together': '함께', 'courage': '용기'},
    '정보': {'list': '리스트', 'loop': '반복', 'input': '입력', 'python': '파이썬',
           'output': '출력', 'variable': '변수', 'function': '함수', 'algorithm': '알고리즘'},
}
# 2차원 리스트: 난이도표[행] = [이름, 최소 글자 수, 최대 글자 수, 뜻 힌트 제공]
난이도표 = [['쉬움', 3, 5, True],
            ['보통', 5, 6, False],
            ['어려움', 7, 20, False]]
# 2차원 리스트: 키보드판 (행 = 키보드 줄, 열 = 글자)
키보드판 = [list('qwertyuiop'),
            list('asdfghjkl'),
            list('zxcvbnm')]

def 구조대게임소개():
    print('*' * 44)
    print(' 영단어 구조대 - 주제와 난이도를 골라 출동하세요')
    print(f' 알파벳 한 글자씩 입력, {최대틀림}번 틀리면 신호가 끊겨요!')
    print('*' * 44)

def 번호선택(안내문, 선택지):
    """선택지(리스트)를 번호와 함께 보여 주고, 올바른 번호가 들어올 때까지 다시 묻는다"""
    for i in range(len(선택지)):
        print(f'  {i + 1}. {선택지[i]}')
    while True:
        text = input(안내문 + ' > ').strip()
        if text.isdecimal() and 1 <= int(text) <= len(선택지):
            return int(text) - 1                 # 인덱스로 돌려준다
        print(f'1~{len(선택지)} 사이의 번호를 입력하세요.')

def 비밀단어생성(주제, 난이도):
    """주제의 단어 중 난이도 글자 수에 맞는 단어를 무작위로 고른다"""
    최소, 최대 = 난이도[1], 난이도[2]          # 난이도 = ['쉬움', 3, 5, True] 같은 한 행
    후보 = []
    for 단어 in 단어사전[주제]:                 # 딕셔너리를 for 로 돌리면 키(영단어)가 하나씩 나온다
        if 최소 <= len(단어) <= 최대:
            후보.append(단어)
    if len(후보) == 0:                           # 맞는 단어가 없으면 전체에서 고른다
        후보 = list(단어사전[주제])
    return random.choice(후보)

def 밑줄단어(비밀단어, 맞춘단어):
    """맞힌 글자는 보여 주고 나머지는 _ 로 바꾼 문자열을 돌려준다"""
    결과 = ''
    for 글자 in 비밀단어:
        if 글자 in 맞춘단어:
            결과 = 결과 + 글자 + ' '
        else:
            결과 = 결과 + '_ '
    return 결과

def 구조대위치(비밀단어, 맞춘단어):
    """맞힌 글자 비율만큼 구조대가 친구에게 다가간 길을 문자열로 돌려준다"""
    맞힌수 = 0
    for 글자 in 비밀단어:
        if 글자 in 맞춘단어:
            맞힌수 += 1
    칸 = 맞힌수 * 10 // len(비밀단어)          # 맞힌 비율을 0~10칸으로 바꾼다 (// : 몫)
    return '구조대 [' + '=' * 칸 + '>' + ' ' * (10 - 칸) + '] 친구'

def 키보드출력(틀린단어, 맞춘단어):
    """2차원 리스트 키보드판을 중첩 반복문으로 출력한다 (맞힘: 대문자, 틀림: ·)"""
    for 행 in range(len(키보드판)):
        print(' ' * 행, end='')                  # 줄마다 한 칸씩 들여쓰기
        for 열 in range(len(키보드판[행])):
            글자 = 키보드판[행][열]            # 2차원 리스트: [행][열] 순서로 꺼낸다
            if 글자 in 맞춘단어:
                print(글자.upper(), end=' ')
            elif 글자 in 틀린단어:
                print('·', end=' ')
            else:
                print(글자, end=' ')
        print()

def 게임화면생성(틀린단어, 맞춘단어, 비밀단어):
    print(신호그림[len(틀린단어)])
    print(구조대위치(비밀단어, 맞춘단어))
    print(f'남은 배터리: {최대틀림 - len(틀린단어)}칸   틀린 글자: {" ".join(틀린단어)}')
    키보드출력(틀린단어, 맞춘단어)
    print('암호: ' + 밑줄단어(비밀단어, 맞춘단어))

def 알파벳한글자리턴(사용한글자):
    """공백 제거·소문자 변환 후, 사용하지 않은 알파벳 한 글자가 들어올 때까지 다시 묻는다"""
    while True:
        guess = input('알파벳 한 글자 > ').strip().lower()
        if len(guess) != 1:
            print('한 글자만 입력해 주세요.')
        elif guess not in 'abcdefghijklmnopqrstuvwxyz':
            print('알파벳(a~z)만 입력해 주세요.')
        elif guess in 사용한글자:
            print('이미 입력한 글자입니다. 다른 글자를 고르세요.')
        else:
            return guess

def 모두맞췄는지(비밀단어, 맞춘단어):
    for 글자 in 비밀단어:
        if 글자 not in 맞춘단어:
            return False
    return True

def 한판진행(주제, 난이도):
    """한 번 출동하고 [비밀단어, 결과, 틀린 횟수]를 돌려준다"""
    비밀단어 = 비밀단어생성(주제, 난이도)
    맞춘단어, 틀린단어 = '', ''
    print(f'\n[SOS] {주제} / {난이도[0]} - {len(비밀단어)}글자 암호가 도착했어요.')
    if 난이도[3]:
        print('뜻 힌트: ' + 단어사전[주제][비밀단어])   # 딕셔너리 안의 딕셔너리: [주제][영단어] → 뜻
    while True:
        게임화면생성(틀린단어, 맞춘단어, 비밀단어)
        guess = 알파벳한글자리턴(틀린단어 + 맞춘단어)
        if guess in 비밀단어:
            맞춘단어 = 맞춘단어 + guess
            if 모두맞췄는지(비밀단어, 맞춘단어):
                print(f'\n구조 성공! 암호는 {비밀단어} ({단어사전[주제][비밀단어]}) - 친구가 무사히 돌아왔어요!')
                return [비밀단어, '구조', len(틀린단어)]
        else:
            틀린단어 = 틀린단어 + guess
            if len(틀린단어) == 최대틀림:
                print(신호그림[최대틀림])
                print(f'\n신호가 끊겼어요. 암호는 {비밀단어} ({단어사전[주제][비밀단어]}) - 다시 출동해요!')
                return [비밀단어, '재출동', len(틀린단어)]

def 기록표출력(기록표):
    """2차원 리스트 기록표를 중첩 반복문으로 표처럼 출력한다"""
    제목줄 = ['출동', '주제', '난이도', '단어', '결과', '틀림']
    for 행 in [제목줄] + 기록표:
        for 칸 in 행:
            print(str(칸).ljust(10), end='')   # ljust(10): 10칸 너비로 왼쪽 정렬 (한글은 2칸 차지해 조금 어긋날 수 있음)
        print()

def 게임재실행():
    return input('다시 출동할까요? (y/n) > ').strip().lower().startswith('y')

def main():
    구조대게임소개()
    점수 = {'구조': 0, '재출동': 0}               # 딕셔너리: 결과별 횟수
    기록표 = []                                  # 2차원 리스트: [[출동, 주제, 난이도, 단어, 결과, 틀림], ...]
    주제목록 = list(단어사전.keys())
    난이도이름 = []                              # 난이도표 각 행의 0번 칸(이름)만 모은다
    for 행 in 난이도표:
        난이도이름.append(행[0])
    while True:
        주제 = 주제목록[번호선택('주제 번호', 주제목록)]
        난이도 = 난이도표[번호선택('난이도 번호', 난이도이름)]
        단어, 결과, 틀림 = 한판진행(주제, 난이도)   # 리스트 [단어, 결과, 틀림]을 세 변수로 나눠 받기
        점수[결과] += 1                          # 결과가 '구조'면 점수['구조']가 1 증가
        기록표.append([len(기록표) + 1, 주제, 난이도[0], 단어, 결과, 틀림])
        if not 게임재실행():
            break
    print('\n===== 구조 출동 기록표 =====')
    기록표출력(기록표)
    print(f'총 {len(기록표)}번 출동  구조: {점수["구조"]}명  재출동: {점수["재출동"]}번')

if __name__ == '__main__':
    main()
```

## 정리

- 딕셔너리 {키: 값} → 이름(키)으로 값을 찾는다
- 딕셔너리로 결과별 횟수 세기: 점수[결과] += 1
- 2차원 리스트 [행][열] → 표 모양 데이터
- 중첩 for: 바깥은 행, 안쪽은 열
