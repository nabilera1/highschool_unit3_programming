## 연수 목표

1. 행맨을 '사람을 돕는' 영단어 구조대로 재구성한 의도를 이해하고, 수업 소재를 긍정적으로 다시 디자인하는 관점을 갖는다.
2. 게임 하나를 단계적으로 키우는 8차시 흐름(기본 → 테스트 → 함수 → 자료구조 → 프로젝트)을 직접 체험한다.
3. 코딩 테스트 자동 검증, 루브릭, 활동지를 자기 학교 수업에 맞게 조정할 수 있다.

## 3시간 압축 과정

| 시간 | 주제 | 활동 | 자료 |
| --- | --- | --- | --- |
| 0:00~0:20 | 여는 활동 | 산출물 예시(`new_rescue_3_project.py`) 플레이, 행맨과 비교 토의 | 1차시 PPT |
| 0:20~1:00 | 기본 버전 만들기 | 2~4차시 코드를 차례로 실행·수정, 빈칸 채우기 체험 | step1, step2, basic, blank |
| 1:00~1:10 | 휴식 | | |
| 1:10~1:50 | 테스트와 함수 | 일부러 오류 입력 넣기 → 입력 검사 버전 비교, 함수 버전 리팩터링 따라가기 | 5·6차시 페이지 |
| 1:50~2:30 | 자료구조 확장 | 단어사전에 새 주제 추가, 난이도표 행 추가, 글자 빈도 분석 | 7·8차시 페이지 |
| 2:30~3:00 | 수업 설계 나눔 | 우리 학교 적용 계획(차시 조정, 평가) 작성·공유 | 루브릭, 과정안 |

## 6시간 실습 과정

| 차수 | 주제 | 내용 |
| --- | --- | --- |
| 1 (1시간) | 문제 발견 | 게임 플레이, 입력–처리–출력 분석, 상태 변수 찾기 (1차시 활동지를 교사가 직접 작성) |
| 2 (1시간) | 기본 구현 | 리스트·for·while로 기본 버전 완성 (2~4차시) |
| 3 (1시간) | 테스트·개선 | 테스트 케이스 표 작성, 학생 오개념(빈 문자열, isalpha와 한글) 토의 (5차시) |
| 4 (1시간) | 함수·자료구조 | 함수 버전 → 확장 버전 코드 읽기, 코딩 테스트 풀기 (6~7차시) |
| 5 (1시간) | 프로젝트 | 출발 코드로 연수자 모둠 프로젝트 제작 (8차시) |
| 6 (1시간) | 평가·적용 | 루브릭으로 서로의 산출물 평가, 우리 학교 수업 설계 발표 |

## 중학교 수업에 적용할 때

| 조정 항목 | 방법 |
| --- | --- |
| 차시 | 1~4차시 중심(기본 버전 완성까지), 5·6차시는 시간에 따라 선택 |
| 코드 | 기본 버전과 빈칸 채우기 위주, 7차시 코드는 '단어장 바꾸기'만 |
| 도전 과제 | '기본' 위주, 빠른 학생에게 '응용' |
| 코딩 테스트 | 문제 1(기본)만, 예제 입력을 칠판에 함께 풀이 |
| 평가 | 활동지와 관찰 중심, 프로젝트는 '단어장 + 메시지 꾸미기' 수준 |
