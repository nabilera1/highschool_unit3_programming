## 프로젝트 평가 루브릭 (8차시 나만의 영단어 구조대)

| 평가 요소 | 상 | 중 | 하 | 평가 역량 | 지도 유의사항 및 피드백 |
| --- | --- | --- | --- | --- | --- |
| 기획 (기획표) | 주제·대상·추가 기능 2개와 필요한 자료구조·함수를 구체적이고 논리적으로 작성함 | 주제와 기능을 작성하였으나 자료구조·함수 설계가 부분적임 | 도움을 받아 기획표 일부를 작성함 | 컴퓨팅 사고력(분해·추상화) | "이 기능은 어떤 데이터를 기억해야 하니?"처럼 질문으로 안내 |
| 산출물 (코드) | 기획한 기능을 모두 구현하고 딕셔너리·2차원 리스트·함수를 적절히 활용하며 예외 입력을 처리함 | 기능을 대부분 구현하였으나 자료구조 활용 또는 예외 처리가 부분적임 | 도움을 받아 출발 코드의 일부를 수정함 | 컴퓨팅 사고력(알고리즘·자동화) | 코드 설명 질의로 이해 여부 확인, AI 활용 기록 확인 |
| 테스트 (테스트 기록) | 정상·경계·예외 테스트를 3개 이상 기록하고 발견한 오류를 고친 과정을 설명함 | 테스트를 기록하였으나 예외 테스트 또는 수정 과정이 부분적임 | 도움을 받아 테스트 일부를 기록함 | 문제 해결력, 비판적 사고 | 5차시 테스트 표 양식 다시 안내 |
| 발표·피드백 | 대상·시연·핵심 코드·해결한 오류를 명확히 발표하고 동료에게 구체적인 칭찬 1 + 제안 1을 줌 | 시연과 핵심 코드를 발표하였으나 설명 또는 피드백이 부분적임 | 도움을 받아 시연 위주로 발표함 | 협력적 문제 해결, 의사소통 | 피드백 예시 문장 제공, 저작권·출처 표기 점검 |

## 수행평가 채점 기준표 (학교 계획 「알고리즘 문제 프로그래밍하기」 예시)

평가 방법: 실험·실습, 프로젝트 / 교사 관찰 및 기록

| 채점 요소 | 수행 수준 | 세부 기준 | 배점 |
| --- | --- | --- | --- |
| 문제 분해 및 추상화 (20) | A·B | 게임 규칙을 스스로 분석하여 입력, 처리, 출력의 단계로 정확히 분해하고, 필요한 데이터(상태)를 변수·자료구조로 논리적으로 모델링함 | 20 |
|  | C·D | 입력, 처리, 출력의 단계로 분해하고, 필요한 데이터를 부분적으로 모델링함 | 15 |
|  | E | 도움을 받아 분석 및 분해하고, 일부 모델링함 | 10 |
| 다차원 데이터 구조의 적용 (25) | A | 2차원 리스트, 딕셔너리 자료구조를 활용하여 효율적으로 문제를 해결함 | 25 |
|  | B | 2차원 리스트, 딕셔너리 자료구조를 활용하여 문제를 해결함 | 20 |
|  | C | 2차원 리스트, 딕셔너리 자료구조를 활용하여 일부 문제를 해결함 | 15 |
|  | D | 2차원 리스트, 딕셔너리 자료구조 활용 시 도움을 받아 문제를 해결함 | 10 |
|  | E | 2차원 리스트, 딕셔너리 자료구조를 활용하지 않고 문제를 해결함 | 5 |
| 복합 제어 구조의 설계 (20) | A·B | 중첩 반복문과 다중 조건문을 설계하고 처리하며, 목적에 맞는 프로그램을 작성함 | 20 |
|  | C·D | 중첩 반복문과 다중 조건문을 부분적으로 설계하고 처리하며, 도움을 받아 프로그램을 작성함 | 15 |
|  | E | 중첩 반복문과 다중 조건문을 부분적으로 이해하고, 도움을 받아 일부 작성함 | 10 |
| 프로그램 구현 및 최적화 (20) | A·B | 예외 상황까지 완벽하게 처리하며, 목적에 맞는 효율적인 프로그램을 작성함 | 20 |
|  | C·D | 예외 상황까지 일부 처리하며, 도움을 받아 목적에 맞는 프로그램을 작성함 | 15 |
|  | E | 예외 상황까지 일부 처리하며, 도움을 받아 부분적으로 프로그램을 작성함 | 10 |
| 산출물 완성도 (15) | A·B | 프로그램 산출물을 정확한 위치에 저장하고 제출함 | 15 |
|  | C·D | 프로그램 산출물을 도움을 받아 해당 위치에 저장하고 제출함 | 10 |
|  | E | 프로그램 산출물을 해당 위치에 도움을 받아 부분적으로 저장하고 제출함 | 5 |

- 기본점수(수업과 수행평가에 참여하였으나 산출물이 없는 경우): 35점
- 배점과 기본점수는 **예시**입니다. 각 학교의 평가 계획에 맞게 조정하세요.
- 인공지능(AI)은 소스코드 작성, 오류 수정 범위에서만 활용할 수 있으며, 활동지 서식에 활용 과정을 표기한다.
- AI 입력창에 본인이나 타인의 학번, 이름, 학교명 등 개인정보를 입력해서는 안 된다.
- AI 생성물을 그대로 제출하거나, 결과물의 내용을 묻는 교사의 질의에 적절히 답하지 못하는 경우 해당 내용은 채점에서 제외될 수 있다.

## 코딩 테스트 채점 기준 (형성평가)

| 수준 | 기준 |
| --- | --- |
| 상 | 예제와 교사 추가 입력(경계·예외) 모두 출력이 정확하고, 코드의 각 부분을 설명할 수 있음 |
| 중 | 예제 출력은 정확하나 일부 추가 입력에서 오류가 있거나 설명이 부분적임 |
| 하 | 출력 형식이 다르거나 도움을 받아 일부만 해결함 |
