## 입출력과 변수

| 코드 | 뜻 |
| --- | --- |
| `print(a, b)` | 출력 (사이 공백) |
| `print(a, end=' ')` | 줄 바꿈 없이 출력 |
| `x = input('안내 > ')` | 입력 (항상 문자열) |
| `n = int(input())` | 정수로 입력 |
| `words = input().split()` | 한 줄의 단어들을 리스트로 |
| `f'암호 {비밀단어}'` | f-문자열 |
| `f'{p:.1f}'` | 소수 첫째 자리까지 |

## 문자열

| 코드 | 뜻 | 예 |
| --- | --- | --- |
| `len(s)` | 글자 수 | `len('help')` → 4 |
| `s[0]`, `s[-1]` | 첫 글자, 마지막 글자 | `'help'[0]` → `'h'` |
| `'e' in s` | 포함 여부 | `'e' in 'help'` → True |
| `s + t` | 이어 붙이기 | `'he' + 'lp'` → `'help'` |
| `s * n` | 반복 | `'_ ' * 3` → `'_ _ _ '` |
| `s.strip()` | 앞뒤 공백 제거 | `' e '` → `'e'` |
| `s.lower()` / `s.upper()` | 소문자 / 대문자 | `'H'` → `'h'` |
| `' '.join(s)` | 글자 사이에 공백 | `' '.join('___')` → `'_ _ _'` |

주의: `'' in 'help'`는 True, `'ㅎ'.isalpha()`도 True입니다.

## 조건과 반복

```python
if 조건:
    ...
elif 다른조건:
    ...
else:
    ...

for 글자 in 비밀단어:       # 글자를 하나씩
    ...
for i in range(3):          # 0, 1, 2
    ...
while True:                 # 끝날 때까지
    if 끝낼조건:
        break
```

## 자료구조

| 자료구조 | 만들기 | 읽기 | 추가/수정 |
| --- | --- | --- | --- |
| 리스트 | `words = ['help', 'safe']` | `words[0]`, `words[-1]` | `words.append('hope')` |
| 2차원 리스트 | `표 = [['쉬움', 3], ['보통', 5]]` | `표[행][열]` | `표.append(['어려움', 7])` |
| 딕셔너리 | `뜻 = {'help': '도움'}` | `뜻['help']`, `뜻.get('x', 0)` | `뜻['safe'] = '안전한'` |

## 함수

```python
def 모두맞췄는지(비밀단어, 맞춘단어):    # 매개변수
    for 글자 in 비밀단어:
        if 글자 not in 맞춘단어:
            return False                 # 돌려주고 즉시 끝
    return True

결과 = 모두맞췄는지('help', 'phle')      # 호출 → True

if __name__ == '__main__':
    main()
```
