## 파이썬 설치

1. [python.org](https://www.python.org/downloads/)에서 Python 3.10 이상을 내려받습니다.
2. 윈도우 설치 첫 화면에서 **Add python.exe to PATH**를 반드시 체크합니다.
3. 명령 프롬프트(터미널)에서 확인합니다.

```bash
python --version
```

## 편집기 고르기

| 편집기 | 장점 | 추천 대상 |
| --- | --- | --- |
| IDLE | 파이썬과 함께 설치, 가볍다 (F5 실행) | 처음 배우는 학생, 중학생 |
| IDLE 두 창 띄우기 | 4차시에 nofunc·full 두 파일을 나란히 열어 비교 | 4차시 |
| VS Code + Python 확장 | 자동 완성, 디버거, 터미널 내장 | 프로젝트(8차시), 익숙한 학생, 두 파일 나란히 비교(분할 화면) |
| 웹 IDE | 설치 없이 브라우저에서 실행 | 실습실 설치가 어려운 경우 |

영단어 구조대는 **표준 파이썬만** 사용합니다. 따로 설치할 라이브러리가 없습니다.

## 실행 방법

```bash
python word_rescue.py
```

IDLE에서는 파일을 연 뒤 **F5**를 누릅니다. 게임이 시작되면 아래 셸 창에 알파벳을 입력합니다.

## 코드 이름 규칙

이 책의 코드는 `make_board`, `ask_letter`처럼 **하는 일이 드러나는 영어 이름**을 씁니다. 1차시에 만든 '자료 이름표'를 참고하세요.

| 이름 | 뜻 |
| --- | --- |
| `WORDS` | 암호 단어장 {영단어: 뜻} |
| `word` | 이번 암호 |
| `guessed` | 말한 글자 리스트 |
| `battery`, `MAX_BATTERY` | 남은 배터리 칸 수, 처음 칸 수(6) |
| `records` | 출동 기록표 (2차원 리스트) |

대문자 이름(`WORDS`, `MAX_BATTERY`)은 게임 도중 바뀌지 않는 값이라는 약속입니다.

## ■ □ 같은 특수 문자 입력하기

| 방법 | 하는 법 |
| --- | --- |
| 윈도우 한글 자판 | 한글 상태에서 **ㅁ** 입력 → **한자** 키 → **Tab**으로 목록 펼치기 → ■ □ 선택 |
| 맥 | **Control + Command + Space** → 문자 뷰어에서 'square' 검색 |
| 유니코드 | `'\u25a0'` ■, `'\u25a1'` □, `'\u2665'` ♥ |
| 복사·붙여 넣기 | 이 페이지의 ■ □를 복사해 코드에 붙여 넣기 |

## 자주 만나는 문제

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| `'python'은(는) 내부 또는 외부 명령...` | PATH 미설정 | 재설치하며 PATH 체크, 또는 `py` 명령 사용 |
| 알파벳을 쳤는데 '알파벳 한 글자만 입력하세요.'가 나옴 | 한글 자판 상태 | 한/영 키로 영문 자판으로 바꾸기 |
| ■ □가 ?나 네모 깨짐으로 보임 | 편집기·터미널 글꼴 | IDLE: Options → Configure IDLE에서 '맑은 고딕' 등으로 글꼴 변경 |
| `SyntaxError` (빈칸 채우기 파일) | 빈칸 `____①____`이 남아 있음 | ①~⑥을 모두 채운 뒤 실행 |
| `IndentationError` | 들여쓰기가 맞지 않음 | 들여쓰기는 스페이스 4칸으로 통일 |
| 출동 기록표의 세로줄이 어긋남 | 한글이 영문의 두 배 폭이 아닌 글꼴 | IDLE: Options → Configure IDLE에서 D2Coding·굴림체 같은 고정폭 글꼴로 변경 |
| 게임이 끝나지 않음 | while 조건에 쓰인 변수를 바꾸지 않음 | Ctrl + C로 멈춘 뒤 `battery -= 1` 확인 (5차시) |
