## 본시(5차시) 지도안 요약

| 항목 | 내용 |
| --- | --- |
| 단원 | 알고리즘과 프로그래밍 – 영단어 구조대 프로젝트 |
| 차시 | 5 / 8차시 (50분) |
| 학습 목표 | 1. while 문의 반복 조건과 return으로 게임이 끝나는 두 경우(성공·실패)를 설계할 수 있다. 2. 함수를 조립하여 영단어 구조대의 한 판(play)을 완성하고 규칙을 바꿀 수 있다. |
| 성취 기준 | [12정보03-07] 다양한 제어 구조를 복합적으로 활용한 프로그램을 작성한다. |
| 수업 자료 | word_rescue.py, 5차시 PPT, 암호판·배터리 추적표, 순서도 카드(모둠별 6장), 퀴즈앤보드 |

| 흐름 | 핵심 질문 | 교수-학습 활동 |
| --- | --- | --- |
| 열기 – 동기 유발 (5분) | “컴퓨터는 언제까지 글자를 물어봐야 할까?” | 칠판에 `_ _ _ _`, 종이 구조대 한 판(암호 help, 배터리 6칸) → 멈추는 두 경우(모두 맞힘 / 배터리 0칸) 찾기 |
| 학습 목표 안내 (2분) | | 목표 2개 안내 |
| 기초 개념 질문 (8분) | “횟수가 정해지지 않은 반복은 어떻게 쓸까?” | while 조건(`while battery > 0:`), 반복 안의 return, 퀵 퀴즈 |
| 주제 선정 관련 화두 (7분) | “실행하기 전에 화면을 먼저 맞혀 볼까?” | 탐구 1: play("help")에 h → x → e → l → p 입력 시 화면 예측 → 실행 비교 |
| 해결 방안 모색 (8분) | “play() 안에서 일이 어떤 순서로 일어날까?” | 탐구 2: 순서도 카드 배열, 성공 검사가 입력보다 먼저인 이유, 값 2개 반환 |
| 구현 (10분) | “게임 규칙을 바꾸려면 어디를 고치면 될까?” | 탐구 3: 짝과 미션 ① 쉬운 모드 ② 단어 2개 추가 ③ (도전) 틀린 글자 기록 |
| 오류 수정 (3분) | “battery -= 1을 지우면 어떻게 될까?” | 끝나지 않는 반복 확인, Ctrl + C, 조건 변수는 반복 안에서 바뀌어야 함 |
| 더 나은 방법 (2분) | “for 문으로도 만들 수 있을까?” | for는 횟수가 정해진 반복, while은 조건으로 끝나는 반복 |
| 정리 (5분) | “여러 번 출동한 결과는 어떻게 모아 둘까?” | 출구 티켓 3문항, 퀴즈앤보드 공유, 6차시(2차원 리스트) 예고 |
