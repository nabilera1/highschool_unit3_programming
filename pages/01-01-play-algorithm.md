> **1부 게임을 분석하고 기본 버전 만들기** · 1차시 · 수업 단계: **문제 발견**  
> 핵심 개념: 알고리즘, 입력, 처리, 출력, 상태, 반복, 종료 조건

## 학습 목표

1. 영단어 구조대 게임을 실행하고 규칙을 말로 설명할 수 있다.
2. 게임을 입력–처리–출력과 반복·종료 조건으로 분석할 수 있다.
3. 게임이 기억해야 하는 값(상태)을 찾아 변수 이름을 붙일 수 있다.

## 핵심 질문

> **'행맨' 게임을 사람을 살리는 '구조대' 게임으로 바꾸면, 컴퓨터는 무엇을 기억하고 무엇을 반복해야 할까?**

원래 '행맨(Hangman)'은 단어를 맞히지 못하면 사람 그림이 하나씩 완성되는 게임입니다. 규칙은 재미있지만 그림이 잔인하다는 의견이 많습니다.

그래서 이 책에서는 이야기를 바꿨습니다. **산에서 길을 잃은 친구가 영단어 암호로 SOS를 보냈고, 우리가 알파벳을 맞혀 암호를 완성하면 구조 헬기가 출동합니다.** 틀린 글자를 말하면 그림이 그려지는 대신 **구조 신호 배터리**가 한 칸씩 줄어듭니다. 규칙은 행맨과 같지만 '사람을 돕는' 게임이 되었습니다.

오늘은 완성된 게임을 먼저 플레이해 보고, 그 안에 숨은 **알고리즘**을 찾아봅니다.

## 게임 규칙 정리

| 규칙 | 내용 |
| --- | --- |
| 시작 | 컴퓨터가 단어장에서 영단어 암호 하나를 몰래 고른다 |
| 화면 | 암호는 글자 수만큼 `_`로 보인다. 예: `help` → `_ _ _ _` |
| 입력 | 알파벳 한 글자를 입력한다 |
| 맞힘 | 암호에 있는 글자면 그 자리의 `_`가 글자로 바뀐다 |
| 틀림 | 암호에 없는 글자면 구조 신호 배터리가 한 칸 줄어든다 `■■■■■□` |
| 성공 | 모든 글자를 맞히면 **구조 성공!** |
| 다시 출동 | 6번 틀려 배터리가 0칸이 되면 정답을 보여 주고 다시 출동한다 |

## 입력–처리–출력으로 나누기

| 구분 | 영단어 구조대에서 |
| --- | --- |
| 입력 | 알파벳 한 글자 (키보드) |
| 처리 | 암호에 있는지 확인 → 맞힌 글자 또는 틀린 글자에 기록 → 끝났는지 확인 |
| 출력 | 신호 배터리 그림, 틀린 글자, 밑줄 암호, 성공/실패 메시지 |

**반복**되는 부분은 '화면 보여 주기 → 입력 → 판정'입니다. 반복이 끝나는 **종료 조건**은 두 가지입니다.

1. 암호의 글자를 모두 맞혔다 → 구조 성공
2. 6번 틀렸다 → 신호 끊김

## 게임이 기억해야 하는 값 (상태)

게임 도중 계속 바뀌거나 기억해야 하는 값을 **상태**라고 합니다. 상태마다 변수를 하나씩 만듭니다.

| 기억할 것 | 변수 이름 | 처음 값 | 예 (게임 중) |
| --- | --- | --- | --- |
| 암호(비밀 단어) | `비밀단어` | 무작위로 고른 단어 | `'help'` |
| 맞힌 글자들 | `맞춘단어` | `''` (빈 문자열) | `'hp'` |
| 틀린 글자들 | `틀린단어` | `''` | `'zx'` |
| 틀린 횟수 | `len(틀린단어)` | 0 | 2 |

틀린 횟수를 따로 세지 않고 `len(틀린단어)`로 구하는 점을 눈여겨보세요. **같은 정보를 두 번 저장하지 않으면** 실수가 줄어듭니다.

## 알고리즘을 글로 쓰기 (의사코드)

```text
암호를 무작위로 고른다
맞춘단어, 틀린단어를 빈 문자열로 만든다
반복:
    신호 그림, 틀린 글자, 밑줄 암호를 보여 준다
    알파벳 한 글자를 입력받는다
    만약 글자가 암호에 있으면:
        맞춘단어에 추가한다
        모든 글자를 맞혔으면 → '구조 성공' 출력 후 반복 끝
    아니면:
        틀린단어에 추가한다
        6번 틀렸으면 → '신호 끊김' 출력 후 반복 끝
```

이 의사코드가 4차시에 완성할 **기본 버전 코드의 설계도**가 됩니다. 순서도로 그리면 다음과 같습니다.

```text
        [시작]
          ↓
   (암호를 무작위로 고르기)
          ↓
 ┌→ (신호 그림 · 틀린 글자 · 밑줄 암호 출력)
 │        ↓
 │   /알파벳 한 글자 입력/
 │        ↓
 │   <암호에 있나?> ──예──→ (맞춘단어에 추가) → <모두 맞혔나?> ──예──→ [구조 성공]
 │        │아니오                                   │아니오
 │        ↓                                         │
 │   (틀린단어에 추가) → <6번 틀렸나?> ──예──→ [신호 끊김]
 │                          │아니오                  │
 └──────────────────────────┴───────────────────────┘
```

### 문제 1. 밑줄 암호 만들기 (기본)

영단어 암호 하나를 입력받아 첫째 줄에 `글자 수: n`, 둘째 줄에 글자 수만큼의 `_`를 한 칸씩 띄어 출력하세요.

- 입력: 영단어 하나 (소문자)
- 출력: `글자 수: n` 과 밑줄 암호

예제 입력 1

```text
help
```

예제 출력 1

```text
글자 수: 4
_ _ _ _
```

예제 입력 2

```text
together
```

예제 출력 2

```text
글자 수: 8
_ _ _ _ _ _ _ _
```

### 문제 2. 이 글자는 몇 번? (도전)

첫째 줄에 암호, 둘째 줄에 알파벳 한 글자를 입력받아 그 글자가 암호에 몇 번 있는지 출력하세요. 있으면 `n번 있어요`, 없으면 `없어요`를 출력합니다. (반복문으로 직접 세어 보세요.)

- 입력: 암호, 알파벳 한 글자
- 출력: `n번 있어요` 또는 `없어요`

예제 입력 1

```text
together
e
```

예제 출력 1

```text
2번 있어요
```

예제 입력 2

```text
help
z
```

예제 출력 2

```text
없어요
```

## 정리

- 행맨 규칙을 '사람을 돕는' 구조대 이야기로 바꿨다
- 게임 = 입력 → 처리 → 출력의 반복
- 종료 조건은 두 가지: 모두 맞힘, 6번 틀림
- 게임의 상태(비밀단어·맞춘단어·틀린단어)를 변수로 기억한다
