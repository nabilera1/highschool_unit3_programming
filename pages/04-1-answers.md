## 코딩 테스트 정답 코드

모든 정답 코드는 [source/solutions](https://github.com/nabilera1/highschool_unit3_programming/tree/main/source/solutions) 폴더에 `lesson차시_test번호.py` 이름으로 있습니다. 예제 입력 27개를 모두 넣어 실행해 예제 출력과 같은 결과가 나오는 것을 확인했습니다.

```bash
cd source/solutions
python lesson05_test2.py
```

정답 코드는 **하나의 예시**입니다. 출력이 같고 경계·예외 입력에도 올바르면 다른 풀이도 정답입니다.
