## 확인 퀴즈 정답

**Q1.** `빈도.get('z', 0)`에서 'z'가 딕셔너리에 없으면 결과는?

- ① None
- ② 0
- ③ KeyError
- ④ 'z'

> **정답: ② 0**  
> get(키, 기본값)은 키가 없으면 기본값을 돌려줍니다.

**Q2.** `set('together')`를 쓰는 이유로 알맞은 것은?

- ① 글자를 정렬하려고
- ② 같은 글자를 한 번만 세려고
- ③ 대문자로 바꾸려고
- ④ 글자 수를 세려고

> **정답: ② 같은 글자를 한 번만 세려고**  
> set은 중복을 없애므로, 한 단어에 e가 두 번 있어도 1번만 셉니다.

**Q3.** 단어 24개 중 14개에 e가 있다. 처음에 e를 말하면 맞힐 확률은? (소수 첫째 자리)

## 코딩 테스트 1. 한 단어의 글자 세기

```python
word = input()
세기 = {}
for 글자 in word:
    세기[글자] = 세기.get(글자, 0) + 1     # 처음이면 0에서 시작
for 글자 in sorted(세기):                  # 키를 알파벳 순서로
    print(글자, 세기[글자])
```

**해설** `딕셔너리.get(키, 0) + 1`은 '없으면 0, 있으면 지금 값'에 1을 더하는 세기 패턴입니다. `sorted(딕셔너리)`는 키를 정렬한 리스트를 돌려줍니다.

## 코딩 테스트 2. 첫 글자 추천

```python
words = input().split()
빈도 = {}
for 단어 in words:
    for 글자 in set(단어):          # 한 단어 안의 중복 제거
        빈도[글자] = 빈도.get(글자, 0) + 1

최고 = ''
for 글자 in sorted(빈도):            # 알파벳 순서로 보면서
    if 최고 == '' or 빈도[글자] > 빈도[최고]:   # 더 클 때만 바꾸므로 같으면 앞 글자 유지
        최고 = 글자
p = 빈도[최고] / len(words) * 100
print(f'{최고} {빈도[최고]}개 단어 ({p:.1f}%)')
```

**해설** 심화 코드의 핵심을 문제로 만든 것입니다. 알파벳 순서로 보면서 '더 클 때만' 바꾸면 동점일 때 앞 글자가 남습니다. `:.1f`는 소수 첫째 자리까지 반올림해 표시합니다. 첫 예제에서 l과 p가 모두 3개지만 l이 먼저입니다.
