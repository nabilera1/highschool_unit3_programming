# 01. 교육과정 분석

|---|---|
| **프로젝트 주제** | 행맨 게임 알고리즘을 구현해보며 문제 해결 능력 키우기 |
| **주요 교과(영역)** | 정보(알고리즘과 프로그래밍) |

| **성취 기준** | [12정보03-01] 복잡한 문제를 해결 가능한 작은 문제로 분해하고 모델링한다.<br>[12정보03-06] 다차원 데이터 구조를 활용한 프로그램을 작성한다.<br>[12정보03-07] 다양한 제어 구조를 복합적으로 활용한 프로그램을 작성한다.<br>(연계) [12정보03-09] 실생활 및 다양한 학문 분야의 문제 해결을 위한 프로그램을 협력적으로 설계ㆍ구현한다.<br>(연계) [12정보03-10] 문제 해결을 위한 프로그램의 성능을 평가하고 공유한다. |
| **경남형 AI 디지털 역량** | AI·디지털 자기주도 역량<br>AI·디지털 문제해결 역량<br>AI·디지털 협력적 소통 역량 |
| **핵심 아이디어** | • 복잡한 문제는 해결 가능한 작은 문제로 분해하고, 핵심 요소만 남기는 추상화를 통해 컴퓨터가 처리할 수 있는 형태로 모델링할 수 있다.<br>• 문제에 알맞은 데이터 구조(리스트·2차원 리스트·딕셔너리)와 제어 구조(반복·조건의 중첩)를 선택하면 프로그램을 더 간결하고 효율적으로 만들 수 있다.<br>• 프로그램은 테스트와 개선, 공유의 반복을 통해 더 정확하고 사용하기 좋은 산출물로 발전한다. |
| **핵심 개념** | [핵심 개념] 문제 분해, 추상화(모델링), 알고리즘(순서도·의사코드), 리스트·2차원 리스트·딕셔너리, 문자열 처리(인덱싱·슬라이싱·in 연산자), 중첩 반복문·다중 조건문, 함수(매개변수·반환값), 입력 검증과 테스트<br>[선행 개념] 변수와 자료형(문자열), 연산자(산술·비교·논리), 표준 입출력(input/print), 기본 조건문(if)과 반복문(for/while), random 모듈 |
| **핵심 질문** | 익숙한 놀이(행맨 게임)의 규칙을, 컴퓨터가 이해하고 실행할 수 있는 알고리즘과 프로그램으로 어떻게 바꿀 수 있을까?<br>• 행맨 게임의 규칙을 어떤 작은 문제로 나누어야 할까? (분해)<br>• 비밀 단어·맞힌 글자·틀린 글자·그림 단계처럼 게임에 꼭 필요한 데이터는 무엇이고, 어떤 구조에 담아야 할까? (추상화·데이터 구조)<br>• 대문자·숫자·이미 입력한 글자처럼 어떤 입력에도 내 프로그램이 올바르게 동작한다는 것을 어떻게 확인할 수 있을까? (테스트·개선) |
| **프로젝트 개요** | 단어 맞히기 놀이인 행맨(Hangman) 게임을 공통 소재로 「문제 발견 → 문제 구조화 → 컴퓨팅 설계 → 구현 → 테스트 및 개선 → 공유·확장」의 6단계를 8차시 동안 수행하는 프로젝트이다.<br>학생은 교사가 제공한 행맨 게임을 체험·분석하여 규칙을 입력–처리–출력으로 분해하고, 순서도·의사코드로 알고리즘을 설계한 뒤, 리스트(행맨 그림·단어 목록)·딕셔너리(주제별 단어와 뜻·점수)·2차원 리스트(난이도표·기록표·키보드판)와 중첩 제어 구조를 사용하여 파이썬으로 구현한다. 모둠은 행맨 게임을 확장하거나, 행맨에서 익힌 구조를 적용한 새 텍스트 게임(숫자 야구, 끝말잇기, 영단어 퀴즈 등)을 기획할 수 있다.<br>이어서 반복되는 코드를 함수로 모듈화하고, 정상·경계·예외 입력(대문자, 숫자, 두 글자, 이미 입력한 글자 등)의 테스트 케이스로 오류를 찾아 개선하며, 완성한 게임을 서로 시연하고 피드백한다. |
| **프로젝트 목표** | 1. 행맨 게임의 규칙을 입력·처리·출력 단계의 작은 문제로 분해하고 핵심 요소를 추상화하여 모델링할 수 있다.<br>2. 문제에 적합한 데이터 구조(리스트·2차원 리스트·딕셔너리)를 선택하여 단어·글자·기록 데이터를 저장·가공할 수 있다.<br>3. 중첩 반복문과 다중 조건문을 복합적으로 활용하고, 함수로 모듈화한 게임 프로그램을 작성할 수 있다.<br>4. 테스트 케이스를 설계하여 오류를 찾고 수정하며, 결과물을 공유하고 동료 피드백으로 개선할 수 있다. |
| **수행평가 과제 (탐구 과제)** | [수행평가] 알고리즘 문제 프로그래밍하기 (실험·실습, 프로젝트 / 교사 관찰 및 기록)<br>• 과제: 행맨 게임을 확장(주제·난이도·뜻 힌트·기록 기능 등)하거나 행맨의 구조를 적용한 텍스트 게임 1종을 기획하여 문제 분해 → 설계 → 구현 → 테스트 과정을 활동지에 기록하고, 2차원 리스트·딕셔너리와 복합 제어 구조, 함수를 활용한 게임 프로그램(.py)을 완성하여 제출한다.<br>• 평가 요소(배점): 문제 분해 및 추상화(20), 다차원 데이터 구조의 적용(25), 복합 제어 구조의 설계(20), 프로그램 구현 및 최적화(20), 산출물 완성도(15) – 기본점수 35점<br>• AI는 소스코드 작성·오류 수정 범위에서만 활용하며, 활용 과정을 활동지 서식에 기록한다(개인정보 입력 금지). |
