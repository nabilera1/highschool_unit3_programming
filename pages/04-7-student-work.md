## 3. 과제 B – 출동 기록표: 3번 출동과 성공 기록

> **[과제]** 출동 기록표 코드(main, print_records)를 바꾸어 ① 출동을 3번으로 정해 자동으로 끝나게 하고, ② 기록표 `records`에서 성공한 출동만 골라 출력하시오.  
> 기록표 한 행 = [출동 번호, 암호, 결과, 틀린 횟수] → `row[0]` 출동 번호, `row[1]` 암호, `row[2]` 결과, `row[3]` 틀린 횟수

### 예시 B-상 – 3번 출동 + 성공 기록 출력 (함수)

**수정 코드** ([taskB_high.py](https://github.com/nabilera1/highschool_unit3_programming/blob/main/source/examples/taskB_high.py))

```python
def print_success(records):                        # ★ 새로 만든 함수
    """출동 기록표에서 성공한 출동만 골라 출력하고 성공률을 알려 준다"""
    count = 0
    for row in records:              # 행(출동)을 하나씩
        if row[2] == "성공":          # 3번째 칸(결과)이 성공이면
            print(f"{row[0]}번 출동: {row[1]} ({WORDS[row[1]]}) - 틀린 횟수 {row[3]}")
            count += 1
    print(f"→ 성공 {count}번 / 출동 {len(records)}번, 성공률 {count / len(records) * 100:.0f}%")

def main():
    print("=== 영단어 구조대 === 오늘은 3번 출동합니다!")      # ★
    records = []
    for i in range(3):                         # ★ while True → 3번 출동
        word = pick_word(WORDS)
        success, wrong = play(word)
        records.append([len(records) + 1, word, "성공" if success else "실패", wrong])
    print_records(records)                     # ★ 3번이 끝난 뒤 한 번만 출력
    print("[성공한 출동]")                     # ★
    print_success(records)                     # ★
```

- **해결하지 못한 점:** "성공한 출동만 출력하고 싶었는데, 기록표에서 성공인 행을 어떻게 골라야 할지 모르겠다."

**교사 피드백**

- **잘한 점:** len(records)를 반복 조건으로 써서 '행의 개수 = 출동 횟수'라는 2차원 리스트의 구조를 활용했다.
- **확인할 점:** print_records(records)가 반복 안에 있어 출동마다 표가 다시 출력된다. 들여쓰기를 한 단계 빼면 3번이 끝난 뒤 한 번만 출력된다.
- **다음 단계:** `for row in records:` 안에서 먼저 `print(row[2])`로 결과 칸만 출력해 보자. 그다음 `if row[2] == "성공":`을 붙이면 성공한 출동만 남는다.
- **성취수준:** 중 – 미션 1개 해결

### 예시 B-하 – 교사의 도움을 받아 기록표에서 출동 결과 읽기

```python
# main() 안, print_records(records) 아래에 두 줄 추가
        print_records(records)

```

- **지원 계획:** 다음 차시 첫 활동으로 기록표 읽기를 짝과 묻고 답하기로 한 번 더 연습한다.

## 4. 수준별 비교 정리와 연수 협의 포인트

- **수준을 가르는 기준:** 기능의 개수보다 ① 자료구조(행·칸, 키·값)를 읽고 골라내는 능력, ② 바꾼 줄을 스스로 설명하는 능력, ③ 함수로 나누어 다시 쓰는 능력을 본다.
- **두 과제의 공통 구조:** 과제 A 'guessed에서 틀린 글자만 고르기'와 과제 B 'records에서 성공한 행만 고르기'는 같은 반복 + 조건 구조이다. 중 수준 학생에게는 다른 과제의 상 수준 코드를 연결해 주는 피드백이 효과적이다.
- **교사 도움의 기록:** 하 수준은 '함께 쓴 줄'과 '스스로 쓴 줄'을 코드 주석과 활동지에 구분해 적게 하여, 다음 차시 지원 계획의 근거로 삼는다.
- **피드백 형식:** '잘한 점 + 확인할 점 + 다음 단계'로 쓰고, 다음 단계는 바로 입력해 볼 수 있는 코드 한두 줄 수준으로 구체화한다.
- **연수 활동 제안:** 참여 교사가 여섯 예시를 부록 04-2 평가 기준과 학교 채점 기준표로 직접 채점한 뒤, 채점 결과가 갈린 지점을 중심으로 협의한다.
