## 6단계 문제 해결 수업 모형

8차시는 하나의 큰 문제 해결 과정입니다. 차시마다 중심 단계가 있지만, 각 차시 안에서도 '질문 → 설계 → 구현 → 확인'이 작게 반복됩니다.

| 단계 | 차시 | 영단어 구조대에서 하는 일 |
| --- | --- | --- |
| 문제 발견 | 1 | 행맨을 '사람을 돕는 게임'으로 바꾸고, 플레이하며 입력–처리–출력과 종료 조건 찾기 |
| 문제 구조화 | 2 | 게임에 필요한 데이터(단어장, 암호, 맞힌·틀린 글자)를 변수와 리스트로 추상화 |
| 컴퓨팅 설계 | 3~4 | 추적표·의사코드·순서도로 암호판과 반복을 설계하고 기본 버전 구현 |
| 테스트 및 개선 | 5 | 정상·경계·예외 테스트 케이스로 오류를 찾고 입력 검사로 개선 |
| 구현 | 6~7 | 함수로 구조를 다듬고, 딕셔너리·2차원 리스트로 기능 확장 |
| 공유·확장 | 8 | 나만의 영단어 구조대 프로젝트, 발표와 동료 피드백 |

```text
 문제 발견 → 문제 구조화 → 컴퓨팅 설계 → 테스트 및 개선 → 구현 → 공유·확장
    1            2            3~4             5          6~7       8
```

## 코드가 자라는 과정

```text
new_rescue_step1_secret.py   (2차시)  리스트에서 암호 고르기
        ↓ + for 암호판
new_rescue_step2_board.py    (3차시)  밑줄 암호판, 3번 입력
        ↓ + while, 깃발 변수, 신호그림 리스트
new_rescue_1_basic.py        (4차시)  기본 버전 완성 (입력 검사 없음)

        ↓ + def, return, main()

        ↓ + 딕셔너리, 2차원 리스트, 중첩 반복
new_rescue_3_project.py      (7차시)  확장 버전 (산출물 예시)
        ↓ + 모둠 아이디어

```

## 대상과 운영 방법

| 대상 | 권장 운영 |
| --- | --- |
| 고등학교 「정보」 | 8차시 전체, 코딩 테스트 2문항과 심화 과제까지 |
| 중학교 「정보」 | 1~4차시 중심 + 6차시(함수) 선택, 도전 과제는 '기본' 위주, 7~8차시는 산출물 예시를 고쳐 보는 활동으로 |
| 교사 연수 | 부록 04-3 연수 가이드 (3시간 압축 과정 / 6시간 실습 과정) |

## 수업 방법 키워드

- **PRIMM**: 예측(Predict) → 실행(Run) → 탐구(Investigate) → 수정(Modify) → 만들기(Make). 매 차시 '실행 예시'와 '실습 활동'이 이 순서를 따릅니다.
- **짝 프로그래밍**: 한 명은 입력(드라이버), 한 명은 확인(내비게이터). 10분마다 역할을 바꿉니다.
- **추적표**: 변수 값이 반복마다 어떻게 바뀌는지 표로 따라가며 코드를 읽습니다.
