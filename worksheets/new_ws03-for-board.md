# 3차시 학생 활동지 · for 반복문으로 밑줄 암호판 만들기

> 영단어 구조대(New HangMan Game)  
> 수업 단계: 컴퓨팅 설계

학번: ________  이름: ________  모둠: ________  날짜: ________

## 오늘의 학습 목표

- [ ] for 반복문으로 문자열의 글자를 하나씩 꺼낼 수 있다.
- [ ] for와 if를 함께 써서 맞힌 글자만 보여 주는 암호판을 만들 수 있다.
- [ ] 문자열 누적(+)으로 맞힌 글자를 기록할 수 있다.

## 핵심 질문

> 암호가 4글자일 때도, 8글자일 때도 똑같은 코드로 밑줄 암호판을 만들려면?

나의 생각: ______________________________________________

## 활동 1. 추적표로 암호판 예상하기

비밀단어 = `'rescue'`, 맞춘단어 = `'es'`

| 반복 | 글자 | 글자 in 맞춘단어 | 출력 |
| --- | --- | --- | --- |
| 1 |  |  |  |
| 2 |  |  |  |
| 3 |  |  |  |
| 4 |  |  |  |
| 5 |  |  |  |
| 6 |  |  |  |

최종 암호판: ____________________

## 활동 2. 코드 빈칸 채우기

```python
for 글자 in ________:
    if 글자 ____ 맞춘단어:
        print(글자, end=' ')
    else:
        print(____, end=' ')
print()
```

## 핵심 개념 빈칸 채우기

1. ( ______ ) 글자 in 문자열 → 글자를 하나씩 꺼낸다
2. ( ______ ) + if 로 맞힌 글자만 보여 주는 암호판
3. 맞춘단어 = 맞춘단어 + ( ______ ) 로 기록을 누적한다
4. ( ______ )(n)은 0부터 n-1까지, n번 반복
