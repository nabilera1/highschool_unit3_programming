# 7차시 학생 활동지 · 딕셔너리와 2차원 리스트로 게임 확장하기

> 영단어 구조대(New HangMan Game)  
> 수업 단계: 구현

학번: ________  이름: ________  모둠: ________  날짜: ________

## 오늘의 학습 목표

- [ ] 딕셔너리로 '영단어 → 뜻'처럼 짝지은 데이터를 저장하고 꺼낼 수 있다.
- [ ] 2차원 리스트의 행과 열을 이해하고 중첩 for로 출력할 수 있다.
- [ ] 딕셔너리와 2차원 리스트를 이용해 게임에 새 기능을 추가할 수 있다.

## 핵심 질문

> 암호마다 '뜻 힌트'를 붙이고, 출동 기록을 표로 남기려면 데이터를 어떻게 저장해야 할까?

## 핵심 개념 빈칸 채우기

1. ( ______ ) {키: 값} → 이름(키)으로 값을 찾는다
2. ( ______ )로 결과별 횟수 세기: 점수[결과] += 1
3. ( ______ ) [행][열] → 표 모양 데이터
4. 중첩 ( ______ ) 바깥은 행, 안쪽은 열
