> 영단어 구조대(New HangMan Game) 1~8차시 활동지의 예시 답안입니다. 학생 활동지는 같은 폴더의 `lesson0N_….md` 파일입니다.

## 1차시 활동지 예시 답안 · 영단어 구조대 플레이하고 규칙 찾기

> 영단어 구조대(New HangMan Game)  
> 수업 단계: 문제 발견

> **굵은 글씨**(PDF에서는 굵은 파란 글씨)가 예시 답안입니다. 값과 화면은 코드를 실제로 실행한 결과와 같습니다.

### 오늘의 학습 목표

- [ ] 게임 규칙을 말로 설명할 수 있다.
- [ ] 게임을 입력–자료–처리–출력과 끝나는 조건으로 나눌 수 있다.
- [ ] 게임이 기억해야 하는 자료에 이름을 붙일 수 있다.

### 활동 1. 플레이 기록 (짝과 번갈아 3번 출동)

| 출동 | 암호 | 결과 | 틀린 횟수 | 처음 말한 글자 |
| --- | --- | --- | --- | --- |
| 1 | **help** | **성공** | **1** | **e** |
| 2 | **safe** | **실패** | **6** | **o** |
| 3 | **rescue** | **성공** | **2** | **e** |

### 활동 2. 입력–자료–처리–출력으로 정리하기

| 구분 | 게임에서 일어나는 일 | 코드로 나타낼 것 (자료·명령) |
| --- | --- | --- |
| 입력 | **알파벳 한 글자, 다시 출동할지 y / n** | **input(), ask_letter(guessed)** |
| 자료 (기억할 것) | **단어장(영단어와 뜻), 이번 암호, 말한 글자, 남은 배터리, 출동 기록** | **WORDS, word, guessed, battery, records** |
| 처리 (판단) | **글자가 암호에 있으면 보여 주고, 없으면 배터리를 한 칸 줄인다** | **if g not in word: battery -= 1** |
| 출력 | **암호판, 배터리 그림, 결과 문구(뜻 포함), 출동 기록표** | **make_board(), make_battery(), print_records()** |
| 끝나는 조건 | **성공: 모든 글자를 맞힘 / 실패: 배터리 0칸** | **"_" not in board / while battery > 0 이 거짓** |

### 활동 3. 작은 문제로 나누기

**Q.** 큰 문제(영단어 구조대)를 순서대로 작은 문제 5개로 나누어 보자.

**A.** **암호 고르기 → 암호판 보여 주기 → 글자 받기 → 판단하기 → 기록하기**

**Q.** 틀린 횟수를 따로 변수로 저장하지 않고 구하는 식은?

**A.** **MAX_BATTERY - battery**

### 핵심 개념 빈칸 채우기

1. 입력을 받아 처리하고 출력하는 절차 → ( **알고리즘** )
2. 게임이 기억해야 하는 값 → ( **자료(상태)** )
3. 한 판이 끝나는 두 경우 → ( **모두 맞힘, 배터리 0칸** )

### 도전 과제 체크

| 수준 | 도전 과제 | 완료 |
| --- | --- | --- |
| 기본 | 처음 말하면 좋은 알파벳을 짝과 이야기하기 | □ |
| 응용 | 의사코드에 '이미 말한 글자는 다시 묻기' 추가하기 | □ |
| 심화 | '_ 가 없나?' 검사가 입력보다 먼저 오는 까닭 설명하기 | □ |

## 2차시 활동지 예시 답안 · 규칙을 자료로 정리하기 – 단어장·암호·배터리

> 영단어 구조대(New HangMan Game)  
> 수업 단계: 문제 구조화

> **굵은 글씨**(PDF에서는 굵은 파란 글씨)가 예시 답안입니다. 값과 화면은 코드를 실제로 실행한 결과와 같습니다.

### 오늘의 학습 목표

- [ ] 리스트에 여러 단어를 담고 인덱스로 꺼낼 수 있다.
- [ ] random.choice와 문자열 len·인덱스·in을 쓸 수 있다.
- [ ] 입력에 따른 자료의 변화를 추적표로 따라갈 수 있다.

### 활동 1. 리스트와 문자열 확인 (예측 → 실행)

`words = ["help", "safe", "hope", "rescue"]`, `word = "rescue"`

| 코드 | 예측 | 실행 결과 |
| --- | --- | --- |
| words[1] | **"safe"** | **safe** |
| len(words) | **4** | **4** |
| word[0] | **"r"** | **r** |
| "z" in word | **False** | **False** |
| "■" * 3 + "□" * 3 | **■■■□□□** | **■■■□□□** |

### 활동 2. 암호판·배터리 추적표

`word = "help"`, `MAX_BATTERY = 6` 일 때 h → x → e → l → p 순서로 입력하였다. 각 입력 뒤의 값을 적으시오.

| 순서 | 입력 | guessed | 암호판 | 배터리 | 판단 |
| --- | --- | --- | --- | --- | --- |
| 시작 | – | [ ] | _ _ _ _ | ■■■■■■ (6) | 게임 시작 |
| 1 | h | **["h"]** | **h _ _ _** | **■■■■■■ (6)** | **암호에 있음** |
| 2 | x | **["h", "x"]** | **h _ _ _** | **■■■■■□ (5)** | **없음 → 배터리 1칸 감소** |
| 3 | e | **["h", "x", "e"]** | **h e _ _** | **■■■■■□ (5)** | **암호에 있음** |
| 4 | l | **["h", "x", "e", "l"]** | **h e l _** | **■■■■■□ (5)** | **암호에 있음** |
| 5 | p | **["h", "x", "e", "l", "p"]** | **h e l p** | **■■■■■□ (5)** | **_ 없음 → 구조 성공** |

**Q.** x는 암호판에 나타나지 않는데 왜 guessed에 넣을까?

**A.** **이미 말한 글자를 다시 입력하지 못하게 검사하는 데 쓰기 때문이다. guessed는 '맞힌 글자'가 아니라 '말한 글자' 목록이다.**

### 핵심 개념 빈칸 채우기

1. 리스트의 첫 번째 인덱스 → ( **0** )
2. 리스트 맨 뒤에 값 붙이기 → ( **append()** )
3. 리스트에서 무작위로 하나 고르기 → ( **random.choice()** )

### 도전 과제 체크

| 수준 | 도전 과제 | 완료 |
| --- | --- | --- |
| 기본 | 첫 글자와 마지막 글자를 힌트로 보여 주기 | □ |
| 응용 | 입력한 글자가 몇 번째 자리에 있는지 출력하기 | □ |
| 심화 | MAX_BATTERY를 8로 바꾸면 바뀌는 곳 예측하기 | □ |

## 3차시 활동지 예시 답안 · 문자열·리스트·딕셔너리로 암호판 만들기

### 오늘의 학습 목표

- [ ] for 문으로 암호판을 만들 수 있다.

## 4차시 활동지 예시 답안 · 함수로 나누기 – 함수 없는 코드와 함수 코드 비교

> 영단어 구조대(New HangMan Game)  
> 수업 단계: 컴퓨팅 설계

> **굵은 글씨**(PDF에서는 굵은 파란 글씨)가 예시 답안입니다. 값과 화면은 코드를 실제로 실행한 결과와 같습니다.

### 오늘의 학습 목표

- [ ] def로 함수를 만들고 매개변수·반환값을 쓸 수 있다.
- [ ] 함수 없는 코드와 함수 코드를 비교해 함수의 장점과 한계를 근거로 설명할 수 있다.
- [ ] 함수 설계표를 작성할 수 있다.

### 활동 1. 예측하고 실행하기

**Q.** 도입: 두 코드 중 어느 쪽이 더 좋은 코드일까? (처음 생각)

**A.** **짧은 nofunc 쪽이 좋아 보인다. (수업 끝에 다시 쓰기)**

**Q.** 두 파일에 같은 글자를 넣어 실행한 결과는?

**A.** **화면이 한 글자도 다르지 않았다. 함수로 나누어도 프로그램이 하는 일은 같다.**

### 활동 2. 구간–함수 대응표 (형광펜으로 nofunc 구간 칠하기)

| nofunc 구간 | 하는 일 | full 함수 | 받는 값 | 돌려주는 값 |
| --- | --- | --- | --- | --- |
| [A] | 암호 고르기 | **pick_word** | **words** | **암호 영단어 1개** |
| [B] | 암호판 만들기 | **make_board** | **word, guessed** | **"h _ _ p" 같은 문자열** |
| [C] | 배터리 그림 | **make_battery** | **battery** | **"■■■■□□" 같은 문자열** |
| [D] | 글자 입력·검사 | **ask_letter** | **guessed** | **검사를 통과한 한 글자** |
| [E] | 한 판 진행 | **play** | **word** | **(성공 여부, 틀린 횟수)** |
| [F] | 출동 기록표 출력 | **print_records** | **records** | **없음 (화면 출력)** |
| [F] 안쪽 | 화면 칸 수 세기 | **text_width** | **text** | **칸 수 (한글 2칸)** |

### 활동 3. 수정 실험

| 실험 | 함수 코드 (full) | 함수 없는 코드 (nofunc) |
| --- | --- | --- |
| A. 단어장 미리보기: 추가한 줄 수 | **2줄 (make_board 다시 쓰기)** | **7줄 (암호판 코드 복사)** |
| A. 암호판 모양을 ·로 바꿀 때 고칠 곳 | **1곳 (make_board)** | **2곳 (원래 코드 + 복사한 코드)** |
| B. 셸에서 make_board만 따로 시험 | **가능: make_board("help", ["p"]) → "_ _ _ p"** | **불가능: import 하면 게임이 시작됨** |
| 코드 줄 수 (주석·설명 제외) | **69줄** | **56줄** |
| 가장 깊은 들여쓰기 | **3단계** | **5단계** |

### 활동 4. 만들기와 정리

**Q.** make_battery(battery) 함수를 직접 써 보자.

```python
def make_battery(battery):
    return "■" * battery + "□" * (MAX_BATTERY - battery)
```

**Q.** 함수로 나누면 항상 좋을까? 근거 2가지와 함께 쓰기

**A.** **프로그램이 크고 같은 일이 반복되면 좋다(실험 A: 2줄 대 7줄, 고칠 곳 1곳). 하지만 줄 수가 늘고(69줄 대 56줄) 함수 사이를 오가며 읽어야 하므로, 짧은 프로그램은 함수 없이도 충분하다.**

**Q.** 처음 생각과 비교해 지금 생각은?

**A.** **짧은 코드가 좋은 코드가 아니다. 읽기·고치기·다시 쓰기·따로 시험하기가 쉬운 코드가 좋은 코드다.**

### 핵심 개념 빈칸 채우기

1. 함수를 만드는 키워드 → ( **def** )
2. 함수가 받는 값의 이름 → ( **매개변수** )
3. 함수가 돌려주는 값을 정하는 명령 → ( **return** )
4. 직접 실행할 때만 main()을 부르는 줄 → ( **if __name__ == "__main__":** )

### 도전 과제 체크

| 수준 | 도전 과제 | 완료 |
| --- | --- | --- |
| 기본 | 실험 A를 함수 코드에 넣고 실행하기 | □ |
| 응용 | rescue_bar(word, guessed) 함수 만들기 | □ |
| 심화 | nofunc에 기능 2개 넣고 암호판 모양 바꾸며 고친 곳 세기 | □ |

## 5차시 활동지 예시 답안 · while 문으로 영단어 구조대 게임 완성하기

> 영단어 구조대(New HangMan Game)  
> 수업 단계: 구현

> **굵은 글씨**(PDF에서는 굵은 파란 글씨)가 예시 답안입니다. 값과 화면은 코드를 실제로 실행한 결과와 같습니다.

### 오늘의 학습 목표

- [ ] while 조건과 return으로 게임이 끝나는 두 경우를 설계할 수 있다.
- [ ] 함수를 조립해 play()를 완성하고 규칙을 바꿀 수 있다.

### 활동 1. 예측하고 실행하기

`play("help")`에 h → x → e → l → p를 입력한다.

| 입력 | 예측한 암호판 | 예측한 배터리 | 실행 결과와 같은가? |
| --- | --- | --- | --- |
| h | **h _ _ _** | **■■■■■■** | **○** |
| x | **h _ _ _** | **■■■■■□** | **○ (안내 문구도 나옴)** |
| e | **h e _ _** | **■■■■■□** | **○** |
| l | **h e l _** | **■■■■■□** | **○** |
| p | **h e l p** | **■■■■■□** | **○ → 구조 성공, (True, 1)** |

### 활동 2. 순서도 카드 순서

**Q.** 카드 6장을 순서대로 쓰시오.

**A.** **암호판 출력 → 성공 검사 → 글자 입력 → guessed에 추가 → 없으면 배터리 감소 → 조건 다시 검사**

**Q.** 성공 검사가 입력보다 먼저 오는 까닭은?

## 6차시 활동지 예시 답안 · 출동 기록표 – 2차원 리스트와 중첩 for 문

### 활동 1. 기록표 읽기

`records = [[1, "help", "성공", 1], [2, "safe", "실패", 6], [3, "rescue", "성공", 2]]`

### 핵심 개념 빈칸 채우기

    count = 0

        if g not in word:
