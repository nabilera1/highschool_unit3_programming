# 교수·학습 과정안 · 영단어 구조대(New HangMan Game) (8차시)

> 영단어 구조대 게임을 만들며 배우는 파이썬 프로그래밍  
> 대상: 고등학교 1학년 「정보」 (중학교 적용 가능) · 1차시 45분

## 단원 개요

| 항목 | 내용 |
| --- | --- |
| 단원 | 프로그래밍 (알고리즘과 프로그래밍) |
| 주제 | 행맨을 '사람을 돕는' 영단어 구조대 게임으로 재구성하여 단계적으로 구현하기 |
| 수업 모형 | 6단계 문제 해결 수업 모형 + PRIMM + 짝 프로그래밍 |
| 평가 | 매 차시 형성평가(퀴즈·코딩 테스트·활동지), 8차시 프로젝트 평가(루브릭) |

## 1차시. 영단어 구조대 플레이하고 알고리즘 찾기

- 수업 단계: 문제 발견
- 학습 목표: 영단어 구조대 게임을 실행하고 규칙을 말로 설명할 수 있다. / 게임을 입력–처리–출력과 반복·종료 조건으로 분석할 수 있다. / 게임이 기억해야 하는 값(상태)을 찾아 변수 이름을 붙일 수 있다.
- 핵심 질문: '행맨' 게임을 사람을 살리는 '구조대' 게임으로 바꾸면, 컴퓨터는 무엇을 기억하고 무엇을 반복해야 할까?
- 사용 자료: new_rescue_3_project.py, new_word_rescue_english.py, new_01-play-algorithm.pptx, new_ws01-play-algorithm.md

| 단계 | 시간 | 교수·학습 활동 | 자료·유의점 |
| --- | --- | --- | --- |
| 도입 | 5분 | 행맨 vs 영단어 구조대 비교, 핵심 질문 제시 | PPT 1~2쪽, 핵심 질문 |
| 전개 1 | 15분 | 짝과 게임 플레이, 플레이 기록 작성 | PPT 개념 슬라이드, 짝 프로그래밍 |
| 전개 2 | 15분 | 입력–처리–출력·종료 조건 분석, 상태 변수 찾기 | 활동지, 실행 예시 |
| 정리 | 10분 | 의사코드 함께 쓰기, 확인 퀴즈 | 확인 퀴즈·코딩 테스트, 자기 평가 |

- 평가: 확인 퀴즈 5문항, 코딩 테스트 2문항(기본·도전), 활동지 관찰
